# Moduł Articles

Moduł jest **przygotowany pod przyszłą funkcjonalność artykułów** (lub treści redakcyjnych), ale w repozytorium występuje głównie jako **szkielet struktury**.

## Stan implementacji

Istnieje układ katalogów zgodny z resztą aplikacji (**Application**, **Domain**, **Infrastructure**, **UI**), lecz **brak jest zaimplementowanych klas PHP** (puste foldery pod komendy, zapytania, repozytoria itd.).

## Przeznaczenie (planowane)

Docelowo moduł miałby grupować logikę CRUD lub publikacji artykułów, repozytoria, modele domenowe oraz warstwę HTTP — analogicznie do modułów `Task` czy `Crm`.
